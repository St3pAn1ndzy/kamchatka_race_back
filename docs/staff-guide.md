# Руководство сотрудника фестиваля

Инструкция описывает локальную версию проекта на коммите `7bdf9f8`
Адрес рабочего сервера, учётную запись и контакты дежурного выдаёт ответственный за развёртывание
Функции из незамерженных веток здесь не считаются доступными

## Перед началом смены

1. Получите адрес админки вида `https://<домен>/admin-panel` и личные данные для входа
2. Войдите под своей учётной записью, не передавайте пароль другим сотрудникам
3. Проверьте сезон, дисциплину, этап и номера участников перед вводом данных
4. Узнайте у ответственного, в каком часовом поясе вводится время гонки
5. Согласуйте, кому сообщать о SOS, пропаже координат и ошибках результатов

Демонстрационные пароли из README не предназначены для рабочего сервера
Не создавайте тестовых участников и отметок в рабочем сезоне

## Вход и ошибки авторизации

Панель использует серверную сессию администратора
После окончания смены выйдите из панели через действие выхода
Если сессия истекла или отозвана, войдите заново

В ветке защиты входа действует общий лимит для панели и административного API
По умолчанию разрешено 10 попыток за 60 секунд с одного IP, успешные попытки тоже учитываются
У сотрудников за одним общим внешним IP лимит общий

| Ответ | Что делать |
| --- | --- |
| Неверный логин или пароль | Проверьте раскладку и данные, не повторяйте ввод непрерывно |
| 429 | Подождите время из заголовка Retry-After, при необходимости обратитесь к техническому специалисту |
| 503 при входе | Сообщите техническому специалисту, повторный подбор пароля не поможет |
| Перенаправление на вход | Авторизуйтесь заново, если проблема повторяется, сообщите дежурному |

## Участники и оборудование

В разделе «Участники» доступны участники и трекеры
Проверяйте номер, имя, дисциплину и сезон перед изменениями
У трекера проверяйте номер Iridium, активность и назначение участнику и этапу
Для контролируемого назначения оборудования есть API `POST /api/v1/admin/devices/assign`

Действия активации, снятия и дисквалификации меняют статус участника
Применяйте их только по решению ответственного судьи
Сброс SOS в панели не заменяет связь с участником и выполнение регламента безопасности

## Карта и состояние трекеров

Экран «Гонка и маршрут» показывает маршрут и контрольные пункты выбранного этапа
Карточки участников и монитор трекеров помогают проверить последние доступные данные
Отсутствие свежих координат не доказывает остановку участника
Время GPS-точки может отличаться от времени её получения сервером

Не используйте координаты трекера для определения официального времени прохождения КП
Официальные результаты рассчитываются по судейским отметкам
Если на экране SOS, действуйте по согласованному регламенту, а не только по интерфейсу

## Ручной ввод судейской отметки

1. Откройте раздел «Результаты» → «Отметки» и форму создания
2. Выберите участника и контрольный пункт нужного этапа
3. Укажите фактические дату и время прохождения
4. Укажите штраф и обязательную остановку в минутах, если они назначены
5. Добавьте комментарий при необходимости и сохраните
6. Проверьте сохранённую отметку и протокол выбранного этапа

API ввода отметок принимает дату и время с часовым поясом, например `2026-10-25T14:30:00+03:00`
Настройки отображения времени формы уточняйте у технического специалиста до начала смены

Старая отметка не редактируется напрямую
Исправление выполняется через API `POST /api/v1/admin/marks/{mark_id}/correct`
Он создаёт заменяющую отметку и сохраняет связь с отменённой записью
Причина исправления необязательна
Если у сотрудника нет доступа к этому сценарию, передайте ID отметки и правильные данные ответственному

В списке отметок есть действие «Отменить отметки»
Перед подтверждением проверьте выбранные записи: отменённые отметки исключаются из протокола
Отмена не создаёт правильную отметку автоматически

## Если Iridium недоступен

1. Сообщите техническому специалисту и ответственному судье о времени начала сбоя
2. Продолжайте собирать фактическое время прохождения КП по резервному регламенту
3. Вносите подтверждённые судьями отметки вручную через раздел «Отметки»
4. Не создавайте вымышленные GPS-точки и не заменяйте ими судейское время
5. После восстановления связи проверьте свежесть координат отдельно от протокола

Импорт CSV не является подтверждённым резервным сценарием этой версии
Не загружайте произвольную таблицу, пока формат и реализация импорта не согласованы

## Результаты и рассылки

На экране «Результаты» выберите нужный этап и сверяйте протокол с судейскими данными
Изменение статуса участника и изменение судейской отметки — разные операции

Экран «Рассылка Push» позволяет указать заголовок, текст и получателей
Перед отправкой проверьте аудиторию: рассылку нельзя считать тестовой, если выбраны реальные пользователи
Количество после отправки формы означает поставленные в обработку уведомления, а не подтверждённую доставку каждому пользователю
Состояние обработки смотрите в разделе «Очередь уведомлений»

## Что передать при ошибке

- Время ошибки с часовым поясом и название экрана
- ID этапа, участника, трекера или отметки, если они известны
- Что пытались сделать и что получилось
- Код ответа или текст ошибки, снимок экрана без секретных данных

Не пересылайте пароль, API-ключ Iridium, cookie, JWT или полный файл `.env`
Не удаляйте историю аудита и не запускайте очистку базы для исправления интерфейса

## Приёмка перед передачей сотрудникам

Ответственный должен проверить на отдельном тестовом стенде вход и выход, ввод и исправление отметки,
отмену отметки, просмотр маршрута, назначение трекера и обработку недоступности Iridium
Эта инструкция сверена с исходниками, но не заменяет такую практическую приёмку
Технические команды запуска приведены в [README](../README.md)
